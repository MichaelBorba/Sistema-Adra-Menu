# 🏠 Sistema ADRA – Menu Principal

Página inicial do **Sistema ADRA**, que reúne em cards os módulos de gestão do abrigo. Visual em tons de verde-água, com efeito *glassmorphism* e layout responsivo.

## 📦 Módulos

| Módulo | Descrição | Status |
|---|---|---|
| 📅 Abertura de Plantão | Abertura e fechamento de plantões, escalas e turnos (`plantao.html`) | ✅ Disponível |
| 👥 Gerenciador de Acolhidos | Cadastro, histórico de movimentação e presença (`acolhidos.html`) | ✅ Disponível |
| 📈 Relatórios e Estatísticas | Relatórios, gráficos e análises | 🚧 Em desenvolvimento |
| ⚙️ Configurações do Sistema | Parâmetros, backup e preferências | 🚧 Em desenvolvimento |
| 🛠️ Oficinas | Oficinas, atividades e workshops | 🚧 Em desenvolvimento |
| ❓ Ajuda e Suporte | Documentação e contato do suporte | 🚧 Em desenvolvimento |

## 🛠️ Tecnologias

HTML5, CSS3 e JavaScript puro, com ícones do Font Awesome. Não precisa de instalação.

## 🚀 Como executar

1. Clone o repositório.
2. Mantenha `index.html`, `plantao.html` e `acolhidos.html` na **mesma pasta**.
3. Abra o `index.html` no navegador ou publique com o **GitHub Pages**.

## 📁 Estrutura sugerida

```
/
├── index.html        # Menu principal
├── plantao.html      # Abertura de plantão
├── acolhidos.html    # Gerenciador de acolhidos
└── README.md
```
